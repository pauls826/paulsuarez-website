# paulsuarez.com

Practice website for Paul Suarez, PMHNP-BC, served by GitHub Pages at https://www.paulsuarez.com.

Pages (each is a folder with `index.html`): home, `adult-adhd-treatment/`, `adhd-medication-management/`, `fees/`, `about/`, `faq/`, `referrals/`. Shared styles live in `assets/site.css`. `contact/` and `home/` redirect old Wix links to the homepage.

SEO files: `sitemap.xml` (update when adding pages), `robots.txt`, `llms.txt` (plain-language summary for AI search tools). Each page carries its own title, description, canonical URL and JSON-LD structured data.
